@loyalid/layout-builder

Drop-in Layout Builder UI + Renderer for CMS. Outputs JSON. Bootstrap 4 & 5.

Install
npm install @loyalid/layout-builder
ES Module
import { initLayoutBuilder, generateLayout, generateFullHTML } from '@loyalid/layout-builder';

// Builder UI — syncs JSON to textarea
initLayoutBuilder('#builderContainer', '#layoutData');

// Render JSON → HTML (Bootstrap version: 4 or 5)
const html = generateLayout(data, 5);

// Full standalone HTML page
const page = generateFullHTML(data, { title: 'My Article' });
Script Tag
<script src="/dist/index.js"></script>
<script>
  LoyalidLayout.initLayoutBuilder('#builder', '#jsonData');
  const html = LoyalidLayout.generateLayout(data, 5);
</script>
CMS Integration (Laravel / Blade)
<textarea id="layoutData" name="layout_data" style="display:none;">{!! $article->layout_data !!}</textarea>
<div id="layoutBuilder" style="height:600px;"></div>
<script src="/dist/index.js"></script>
<script>
  LoyalidLayout.initLayoutBuilder('#layoutBuilder', '#layoutData');
</script>
API
FunctionDescription
initLayoutBuilder(container, textarea, opts)Mount builder UI, auto-sync JSON to textarea
generateLayout(data, bootstrap)Render JSON to HTML string. bootstrap: 0 (none), 4, or 5
generateFullHTML(data, opts)Full standalone HTML page from JSON
Features
  • 3-panel builder UI: Style | Order | Preview
  • Blocks: Title, Paragraph, Image, Divider
  • Inline links: [text](url) in content
  • Convert from HTML: paste editor HTML → auto-convert
  • Drag & drop reorder, move up/down, delete
  • Bootstrap 4 & 5 class support
